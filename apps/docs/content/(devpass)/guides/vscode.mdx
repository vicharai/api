The official&nbsp;[Vichar extension](https://marketplace.visualstudio.com/items?itemName=llmgateway.llmgateway-vscode) adds Vichar to the Copilot Chat model picker in VS Code. Connect your key once, then choose from the chat models available to your account.

Verified with VS Code **1.135.0** and the Vichar extension **0.1.0**. The video demonstrates model configuration and a real response without GitHub sign-in.

## Prerequisites

- VS Code 1.134.0 or later with Copilot Chat available.
- An Vichar API key from your&nbsp;[dashboard](https://app.vichar.io/dashboard), or a&nbsp;[DevPass](https://devpass.vichar.io) plan key.

## Install and connect

1. Install **Vichar**, published by **llmgateway**, from the&nbsp;[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=llmgateway.llmgateway-vscode).
2. Open the chat view, click the model picker, and choose **Manage Models…**.
3. Select **Vichar** and enter your API key when prompted.
4. If VS Code prompts you to configure BYOK utility models, set **Chat: Byok Utility Model Default** to **Main Agent Model**.
5. Select an Vichar model from the picker and send a message.

You can also install from the terminal:

```bash
code --install-extension llmgateway.llmgateway-vscode
```

The gateway URL is already configured. Your key is stored in VS Code's secret storage, never in settings files. Run **Vichar: Set API Key** from the Command Palette to replace it, or **Vichar: Clear API Key** to remove it.

## Choose a model

The extension fetches models using your key and lists active chat models with streaming support. Your organization's model access rules and DevPass plan restrictions apply. Browse the&nbsp;[models page](https://app.vichar.io/models) for current capabilities and pricing.

For agent mode, select a model with tool calling. Image attachments require a model with image input support. Responses stream into the chat view.

The extension provides models for Copilot Chat and agent mode. It does not provide inline code completions.

Both PAYG and DevPass keys use the same setup. PAYG requests use your gateway billing configuration; DevPass requests follow your plan's model access and usage limits. The extension sends canonical model IDs, so no provider prefix is needed for DevPass.

BYOK chat works without GitHub sign-in or a Copilot plan. Utility tasks can use the selected model; semantic search and inline completions still have separate authentication requirements. See the&nbsp;[VS Code model documentation](https://code.visualstudio.com/docs/agent-customization/language-models).

## Settings

Search for **Vichar** in VS Code Settings to configure:

| Setting                      | Default                    | Purpose                                                                                                   |
| ---------------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------- |
| `llmgateway.baseUrl`         | `https://api.vichar.io/v1` | Change the endpoint for a self-hosted gateway. Include `/v1`.                                             |
| `llmgateway.models`          | `[]`                       | Limit the picker to specific model IDs. An empty list shows all eligible chat models your key can access. |
| `llmgateway.reasoningEffort` | `default`                  | Override reasoning effort for reasoning-capable models. Choose a level supported by the selected model.   |

Run **Vichar: Refresh Models** to reload the model list, or **Vichar: Open Dashboard** to review usage.

## Troubleshooting

### Models do not appear

Check that the extension is enabled and VS Code meets the minimum version. Run **Vichar: Set API Key**, then **Vichar: Refresh Models**. If you configured `llmgateway.models`, clear it to `[]` to see all eligible models for your key.

### Authentication fails

A `401` response clears the stored key. Run **Vichar: Set API Key** with an active key from your dashboard.

### Credits or plan limits

Read the gateway's error message. PAYG accounts may need credits; DevPass accounts may have reached a plan limit. Check the relevant dashboard before retrying.

For connection errors, open **View → Output** and select **Vichar**. If you use a self-hosted gateway, check `llmgateway.baseUrl`.

Source code and issue reporting are available in the&nbsp;[extension repository](https://github.com/vicharai/api-vscode).
