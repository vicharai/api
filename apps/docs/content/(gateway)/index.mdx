Vichar gives your applications a single OpenAI-compatible API for models from many labs. You get one API key, one base URL, per-request cost tracking, and automatic provider failover.

- **Base URL:** `https://api.vichar.io/v1`
- **Dashboard:** [app.vichar.io](https://app.vichar.io) to create keys, top up credits, and inspect usage
- **Model list:** [vichar.io/models](https://vichar.io/models) or `GET /v1/models`

## How it works

You send a standard OpenAI chat-completions request with a `vichar-*` model ID. Vichar routes it to a healthy provider serving that model, meters the tokens, and deducts the cost from your prepaid credits. If a provider fails, the request is retried on another provider for the same model when one is available.

```bash
curl https://api.vichar.io/v1/chat/completions \
  -H "Authorization: Bearer $VICHAR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vichar-sonnet-5.5",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```
