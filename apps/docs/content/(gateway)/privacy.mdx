icon: ShieldCheck
---

- **Prompt and response content is not stored by default.** The gateway does not log request or response bodies.
- **What is stored**: per-request metadata (model, provider, token counts, cost, latency, timestamps, key and project identifiers) so the dashboard can show activity and analytics.
- Retention levels can be configured per organization; contact support to discuss requirements.

Legal details are in the [Privacy Policy](https://app.vichar.io/legal/privacy).
