The Vichar dashboard gives you full control over your LLM API usage, costs, and configuration. This section walks you through every Vichar dashboard page. DevPass has its own knowledge base: pick the product from the menu at the top of the sidebar, or start at [DevPass](/devpass).

## Switch products

Open the product menu at the top of the dashboard sidebar to switch between **Vichar** and **DevPass**. The checkmark shows your current product. On mobile, open the sidebar first; with a collapsed sidebar, select the Vichar icon.

Switching products opens that product's workspace. It does not transfer API keys, credits, or subscriptions between products. Use the organization selector below the product menu to switch organizations within Vichar.

## AI Gateway

Configure how requests flow through the gateway:

- [**API Keys**](/learn/api-keys) — Create and manage your API keys, plus per-key statistics
- [**Models**](/learn/models) — Browse the full model catalog
- [**Structured Outputs**](/learn/structured-outputs) — Soft JSON output versus strict JSON schema enforcement
- [**Preferences**](/learn/preferences) — Project-level settings like caching

## Observability

Monitor usage, spend, errors, and performance across every request:

- [**Dashboard**](/learn/dashboard) — Overview of your usage, costs, and performance
- [**Activity**](/learn/activity) — Detailed logs of every API request
- [**Model Usage**](/learn/model-usage) — Usage breakdown by model
- [**Usage & Metrics**](/learn/usage-metrics) — Requests, errors, cache rates, and cost trends
- [**Analytics**](/learn/analytics) — Cost, requests, and tokens broken down by model
- [**Member Analytics**](/learn/member-analytics) — Per-member cost and usage breakdowns
