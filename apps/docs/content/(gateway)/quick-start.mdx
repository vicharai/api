## Create an account

Sign up at [app.vichar.io/signup](https://app.vichar.io/signup) and verify your email. A default organization and project are created for you.

</Step>
<Step>

## Create an API key

<ThemedImage
	alt="API keys page"
	basePath="/screenshots/api-keys"
	width={1440}
	height={900}
/>

In the dashboard open **API Keys**, click **Create key**, give it a name, and copy the token. It starts with `vichar_` and is shown only once.

</Step>
<Step>

## Send a request

<Tabs groupId="language" items={["cURL", "Python", "Node"]}>
<Tab value="cURL">

```bash
export VICHAR_API_KEY="vichar_..."

curl https://api.vichar.io/v1/chat/completions \
  -H "Authorization: Bearer $VICHAR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vichar-sonnet-5.5",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

</Tab>
<Tab value="Python">

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.vichar.io/v1",
    api_key="vichar_...",
)

resp = client.chat.completions.create(
    model="vichar-sonnet-5.5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(resp.choices[0].message.content)
```

</Tab>
<Tab value="Node">

```typescript
import OpenAI from "openai";

const client = new OpenAI({
	baseURL: "https://api.vichar.io/v1",
	apiKey: "vichar_...",
});

const resp = await client.chat.completions.create({
	model: "vichar-sonnet-5.5",
	messages: [{ role: "user", content: "Hello" }],
});
console.log(resp.choices[0].message.content);
```

</Tab>

</Step>
<Step>

## Stream it

Set `stream: true` to receive server-sent events:

```bash
curl -N https://api.vichar.io/v1/chat/completions \
  -H "Authorization: Bearer $VICHAR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"vichar-sonnet-5.5","stream":true,"messages":[{"role":"user","content":"Hello"}]}'
```

</Step>
</Steps>

The response is a standard chat completion. `usage.cost` reports the exact USD deducted from your credits.
