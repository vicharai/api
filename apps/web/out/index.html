Frequently asked questions

Is Vichar compatible with the OpenAI SDK?+

Yes. Point your client at https://api.vichar.io/v1 and use a Vichar API key. Your existing code keeps working.

How is usage billed?+

Per token at the model's listed rate, deducted from prepaid credits. Top-ups carry a 5% platform fee and a $20 minimum.

Do you store my prompts?+

No. By default we keep request metadata only: tokens, cost, latency, and which provider served the request.

What happens if a provider goes down?+

Requests automatically reroute to another provider serving the same model when one is available.

Are there rate limits?+

New accounts get 600 requests per minute and 100 concurrent requests. Limits rise as accounts grow.

Can I set spending limits?+

Yes. Every API key can carry its own spend limit, so a runaway workload cannot drain your balance.
